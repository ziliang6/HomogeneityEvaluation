## Task Description
You will be given a model-generated response. Your task is to identify whether the response contains each of the following stylistic features and return the results as a JSON object.

## Factors
1. **opening_template**: The response begins with a phatic or meta-comment before addressing the question (e.g., "That's a great question", "Sure!", "Certainly!", "Of course!"). Do NOT count responses that begin directly with substantive content.

2. **closing_template**: The response ends with a formulaic offer or sign-off addressed to the user (e.g., "Let me know if you have any questions", "I hope this helps", "Feel free to ask if you need clarification"). Do NOT count responses that end with substantive content. If the requested content is itself a letter, email, notice, speech, card, or similar text, closing lines inside that text (e.g., well-wishes, encouragement, thanks, "Best regards", signatures) are part of the content, NOT a closing template.

## Examples

"Absolutely! Here are some coloring book prompts about space exploration for toddlers:
1. A friendly astronaut smiling on a floating moon.
2. A rocket with big windows soaring past stars.
3. A tiny alien waving next to a colorful spaceship.
These prompts are designed to be simple, vivid, and fun for toddlers to color!"
Example Output 1:
{"opening_template": true, "closing_template": true}

2. "Dive Deep: The Ocean's Waves Call Your Name – Don't Miss Out!"
3. "Seize the Wave: The Fear of Missing Out on the Ocean's Majestic Power!""
Example Output 2:
{"opening_template": false, "closing_template": false}

If you'd like a more humorous version, or want me to expand on any part of this notice, please let me know!"

Do not explain your reasoning. Return only the final JSON object with exactly these two boolean fields:
